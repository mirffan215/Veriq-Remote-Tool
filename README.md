# RemoteTool

Free, in-house, AnyDesk-style remote support tool: one portable `RemoteTool.exe` (host + viewer) and a small self-hosted relay.
See `docs/` — start with `BUILD.md`, `SECURITY.md`, `DECISIONS.md` (read **D-02** and **D-15** first), `PROTOCOL.md`. Status: Phase 1 (core remote control) and Phase 2 (clipboard, file transfer, multi-monitor, adaptive quality, resume, address book, relay failover) done; Phase 3 (service/unattended, H.264, Arabic) next. Target OS: Windows 11 / Server 2022.
