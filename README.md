# RemoteTool

Free, in-house, AnyDesk-style remote support tool: one portable `RemoteTool.exe` (host + viewer) and a small self-hosted relay.
See `docs/` — start with `BUILD.md`, `SECURITY.md`, `DECISIONS.md` (read **D-02** and **D-15** first), `PROTOCOL.md`. Roadmap: Phase 1 (this), Phase 2 productivity/relay hardening, Phase 3 service/unattended/H.264/Arabic.
